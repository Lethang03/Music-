# V2 UI SYSTEM

## Design Language
- **Theme**: Premium Dark Mode
- **Palette**: Deep blacks (`#060608`), elevated panels (`#15161d`), and vibrant gradients (Purple to Pink).
- **Typography**: Inter (Weights: 400 to 900) for a clean, geometric feel.
- **Surfaces**: Glassmorphism with deep blurs (`backdrop-filter: blur(24px)`) and subtle structural borders.
- **Motion**: Fast, purposeful transitions (`150ms`). Focus on scale and opacity rather than distracting translations.

## Core Tokens (variables.css)
- `--bg-base`: Core background
- `--accent-gradient`: Primary interactive color
- `--shadow-glass`: Depth for floating elements

## Layout
- **Desktop**: 3-pane layout (Sidebar navigation, Main content area, Global Bottom Player).
- **Mobile**: (In progress) Will utilize a bottom tab bar and a swipe-up full-screen Now Playing sheet.
